# 差制約順列の数え上げ — 本セッションで証明された結果

対象: a_k(n) = |p(i+1) − p(i)| ≥ k (1 ≤ i < n) を満たす [n] の順列数、
および対角族 A_k(n) = a_{n+1}(2n+k) = |差| > n を満たす [2n+k] の順列数
（A179962–A179967 系列。A_k(n) は k = 3..8 が OEIS の各数列に対応）。

各節の冒頭に主張と証明を置き、機械検証はその節末に記す。
証明済み・機械検証済み・未解決の区別は直下の要約と §12 に一覧する。

## 到達状況の要約（本文書の読み方）

主定理（§2）「C_k(shift) が A_k(n) を n ≥ d + q で零化する」の到達状況は
k ごとに異なる:

| k | 漸化式（しきい値以降の全 n での成立） | 根拠 |
|---|---|---|
| 2, 3, 4, 5, 6, 7 | **定理（証明済み）** | 定理 C1 の次数上界 + 認証補題 10.1 + 窓検証（§10） |
| 8 | **未証明**（有限範囲の検証のみ） | 認証に必要な窓（13628 項）が未実行 |
| 一般 k | C_k との同定は**予想**（ただし下記 3 の通り一部は定理） | §12 |

読み違えやすい点が 3 つある:

1. **「認証成立」は検証ではなく証明である。** 定理 C1 により、A_k が次数
   ≤ B(k) の定数係数漸化式を満たすこと自体は（すべての k で）証明されている。
   この次数上界の下では、長さ B(k) の連続窓で C_k 漸化式が成立することが、
   それ以降のすべての n での成立を論理的に含意する（補題 10.1）。したがって
   §10 の表で「完全証明」とある k = 2..7 については、有限計算の結果が
   無限個の n にわたる定理を構成しており、数値実験とは質が異なる。
2. **k = 8 は逆で、どれだけ長くても現状の有限検証は証明ではない。**
   検証窓（n ≤ 45）が認証に必要な窓長（= 次数上界 13628）に達していない
   ため。ただし証明は §10 の手続きの機械的実行（日単位の有限計算）に
   帰着済みである。（k = 7 は同じ手続きの実行により証明が完了した。）
3. **「一般 k は予想」の中身は半分定理である。** 「何らかの定数係数漸化式が
   存在し、次数は明示的な B(k) 以下」は全ての k で定理（C1）。予想として
   残るのは、最小消去多項式がちょうど C_k（根 r(k−r)、奇数 k の中央根 2 重）
   だという**特性多項式の同定**のみ。

初期値・しきい値について: 文書埋込の初期値はすべて厳密計算と一致
（k=8 の値は三系統の独立計算で相互検証）。しきい値 n ≥ d + q は k = 2..8 で
成立開始点として厳密値により確認され、直下でちょうど破れる（sharp）。
ただし k = 8 では「しきい値以降ずっと成立」の部分が上記 2 の通り未証明。

## 0. 記法

- [n] = {1, ..., n}。順列 p の隣接対とは {p(i), p(i+1)}。
- linear forest = 各成分がパス（孤立点を含む）である森。e(F), c(F) は辺数と非自明成分数。
- 対角族では N = 2n+k, V = [N], G = G_{n,k}（u ~ v ⟺ |u − v| > n）とし、
  A_k(n) は G の有向ハミルトンパス数（= 順列数）。
- L = {1..n}, M = {n+1..n+k}, R = {n+k+1..2n+k},
  Γ_L = {1..k−1}, Γ_R = {2n+2..2n+k}, Γ = Γ_L ∪ Γ_R, S = G − M。
- C_k(X) = Π_{r=1}^{⌊k/2⌋} (X − r(k−r))、ただし奇数 k では最終因子（中央根）を 2 重にする。
  d = deg C_k = ⌈k/2⌉, q = max(0, k−3)。
  具体形: C_3 = (X−2)², C_4 = (X−3)(X−4), C_5 = (X−4)(X−6)²,
  C_6 = (X−5)(X−8)(X−9), C_7 = (X−6)(X−10)(X−12)², C_8 = (X−7)(X−12)(X−15)(X−16)。

## 1. 一般恒等式（包除）

**定理 1.1.** 任意のグラフ H（頂点集合 [n]）について、H のどの辺も隣接対に
現れない [n] の順列の個数は

    Sum_{F} (−1)^{e(F)} · 2^{c(F)} · (n − e(F))!

に等しい。F は H の linear forest 全体を走る。

**証明.** 隣接対として実現を強制する辺集合 E ⊆ E(H) で包除する。E が
linear forest でなければ（分岐またはサイクルを含めば）どの順列の隣接対にも
含まれ得ず寄与 0。E が e 辺 c 非自明成分の linear forest なら、各パスを
ブロックに縮約して n − e 個のブロックを並べ（(n−e)! 通り）、各非自明パスに
2 通りの向きがあるので、E を含む順列はちょうど 2^c (n−e)! 個。∎

**検証.** k 差制約（H = G_{n,k}: 0 < |u−v| < k）への特殊化で
k=1: n!、k=2, n=4: 24−36+16−2 = 2、n=5: 120−192+108−24+2 = 14（A002464 と一致）、
k=3, n=4: 24−60+48−12 = 0。さらに実装（perm_gap.rb）が k=1..5, n=1..8 の
全探索と完全一致、k=2 で A002464 を再現。

**命題 1.2（計算量）.** 0 < |u−v| < k のグラフは自然順序で bandwidth ≤ k−1。
よって固定 k に対し、frontier（直近 k−1 頂点）の次数と成分分割を状態とする
転移行列で、辺数の母多項式 f_{n,k}(x) = Σ_F x^{e(F)} 2^{c(F)} を n = 1..N に
ついて一掃きで計算でき、a_k(n) は O(N²) 回の係数演算で全項得られる。
（linear forest では c(F) = v(F) − e(F)（v は被覆頂点数）なので、被覆頂点ごとに
2 を掛け x^j の係数を 2^j F_j として運べば全計算が整数のまま閉じる。）

計算量が式 1.1 の形からではなく bandwidth から来ることも確認済み:
f の最高次係数は 2 × (H のハミルトンパス数) であり、一般の H では #P-困難。

## 2. 対角族の主定理（対象となる主張）

以下が証明対象の主張（外部文書の定理）である:

> 固定 k ≥ 2 に対し、C_k(shift) は A_k(n) を n ≥ d + q で零化する。
> すなわち A_k(n) は特性多項式 C_k の定数係数線形漸化式を満たす。

以降の補題群は、この主張の証明に必要だった 4 つのギャップ
（(1) sector/転移の未定義、(2) サイクル項の扱い、(3) 商環での除算、

k = 8 は有限計算に帰着済み・未実行、一般 k では C_k との同定が予想として残る。

## 3. 補題 A — 中央ブロックの消去と sector の構成（ギャップ (1)）

以下 n ≥ k−1 とする。直接計算で: L, R は独立、M は独立、
N(M_s) = {1..s−1} ∪ {2n+s+1..2n+k} ⊆ Γ、S の辺は L_i R_j ⟺ i < k+j、
**Γ_L の各頂点は S 内で R 全体に、Γ_R の各頂点は L 全体に完全接続**
（i ≤ k−1 < k+j; j ≥ n−k+2 ⟹ k+j > n ≥ i）。

**補題 A1（gadget 分解）.** gadget とは各 s に g(s) ⊆ N(M_s), |g(s)| ∈ {1,2}
を割り当てたもの（辺集合 {M_s γ : γ ∈ g(s)} と同一視）。写像
P ↦ (g_P, F_P)（g_P = P の M 接続辺、F_P = P − M）は

    {G の無向ハミルトンパス} ↔ {(g, F) : F は S の全域 linear forest, F ⊔ g がハミルトンパス}

の全単射であり、A_k(n) = 2 Σ_g N_g(n)、
N_g(n) := #{F : F ⊔ g がハミルトンパス}。gadget の総数は
((k−1) + C(k−1,2))^k 以下で k のみに依存する。

**証明.** M は独立なので M に接続するパス辺はすべて Γ に落ちる。パスから
M を除くと互いに素なパスの族 = L∪R を張る S の linear forest が残り、
F ⊔ g = P で一意に復元される。∎

**補題 A2（trace への崩壊 = sector の定義）.** gadget のグラフの各成分は
Γ と M が交互に並ぶ鎖（サイクルや次数 ≥ 3 を含む g は N_g = 0）。
成分の端の型を Γ_L → L, Γ_R → R, 次数 1 の M（大域端点）→ D とし、

    trace: τ(g) := (成分端型対の多重集合, intL, intR)
    （intL = #{γ ∈ Γ_L : deg_g γ = 2}、intR 同様）

と置くと、**N_g(n) は τ(g) のみに依存する**。trace の総数は k のみに依存。

**証明.** τ(g) = τ(g′) なら、成分同士を端型を保って対応させ、対応する端・
内部頂点・未使用頂点を側ごとに対応させる置換 σ ∈ Sym(Γ_L) × Sym(Γ_R) が取れる。
完全接続性より Γ_L 内（Γ_R 内）の頂点は S で近傍が同一なので σ ∈ Aut(S)。
「F ⊔ g がハミルトンパス」は、(a) 各 γ で deg_F γ ≤ 2 − deg_g γ、
(b) 両端 Γ の各鎖を補助辺に置き換え D 端に端点マーカーを付けた多重グラフが
L∪R を被覆する単一パス、(c) マーカー込み次数 1 の頂点がちょうど 2 個、
と同値であり、g への依存は deg_g の分布・鎖の対形式・D フラグのみを通す
（鎖の長さや M の個体は無関係、頂点総数は共通）。σ はこれらを g から g′ へ
移し S を保つので F ↦ σ(F) が全単射。∎

**系 A3.** A_k(n) = 2 Σ_β m_β N_β(n)。和は trace の有限集合上、係数
m_β = #{g : τ(g) = β} は n によらない定数。**sector := trace** がギャップ (1)
で欠けていた状態空間の定義である。

**検証（全探索、有向パス全列挙 → gadget 分類 → trace 類内の個数一致）.**

| k | n | 総パス数 | gadget 数 | trace 類数 | 類内不一致 |
|---|---|---|---|---|---|
| 3 | 2–5 | 32–352 | 12 | 12 | なし |
| 4 | 3–5 | 1496–24440 | 373 | 31 | なし |
| 5 | 4 | 161136 | 16764 | 66 | なし |

k=5 では 16764 gadget が 66 類に潰れ全類で個数が完全一致。gadget 数・類数が
n によらず安定（k=4 で n=3,4,5 とも 373/31）。

## 4. 補題 B — 代数辞書（ギャップ (2)(3)）

R₃ := Z[x_v : v ∈ V] / (x_v³ : v ∈ V) とし、G の重み付き Laplacian を
L_{uv} = −x_u x_v (u~v), L_{vv} = x_v Σ_{u~v} x_u とする。

**補題 B0.** R₃ 上で det L(v₀|v₀) = Σ_{無向ハミルトンパス P} Π_v x_v^{deg_P(v)}。
Φ を全単項式の係数総和をとる線形汎関数とすると A_k(n) = 2 Φ(det L(v₀|v₀))。

**証明.** Matrix-Tree により Z[x] 上 det L(v₀|v₀) = Σ_{全域木 T} Π x_v^{deg_T v}。
商準同型で R₃ に落とすと deg ≥ 3 の頂点を持つ木が消え、最大次数 ≤ 2 の全域木
= ハミルトンパスのみ残る。∎

注意: x_v = 1 の「代入」は R₃ からの環準同型として存在しない（1³ ≠ 0）。
数え上げの抽出は最後に一度だけ適用する線形汎関数 Φ で行う。

**補題 B1（all-minors 辞書）.** W, W′ ⊆ V, |W| = |W′| = r とする。
Chaiken の all-minors Matrix-Tree 定理により、符号 ε(W,W′) が存在して R₃ 上

    det L(W|W′) = ε(W,W′) Σ_F sgn(π_F) Π_v x_v^{deg_F(v)},

和は「ちょうど r 成分、各成分が W と W′ の元を 1 つずつ含む全域 **linear**
forest F」を走り、π_F は成分の誘導する全単射 W → W′。

**証明.** Chaiken の恒等式は Z[x] 上の多項式恒等式で商写像により R₃ に落ち、
R₃ で次数 ≥ 3 の頂点を持つ森が消える。最大次数 ≤ 2 の森の成分はパス。∎

帰結（ギャップ (2) の解決）: 展開計算のあらゆる中間量はこの形の小行列式、
すなわちそれ自体が「サイクルを一切含まない構造の符号付き数え上げ」に
**恒等的に**等しい。「途中の項でサイクル項は不在」という termwise の主張
（部分展開では偽であり、実際は対相殺で消える）は不要となり、各段階で成り立つ
定理に置き換わる。

**補題 B2（除算なし）.** 消去の 1 ステップを行・列に沿う Laplace 展開
det A = Σ_j (−1)^{i+j} a_{ij} det A(i|j) の反復として定式化すれば、各ステップは
「成分 × より深い小行列式」の Z 線形結合であり除算を含まない。よって零因子を
持つ R₃ 上でもそのまま正当（ギャップ (3) の解決）。Schur 補元（枢軸の可逆性
を要する）はどこにも現れない。∎

## 5. 命題 C — 鏡映障害（ギャップ (4) への確定的部分結果）

**命題 C.** T を有限次元空間 U 上の線形写像、ι を ιTι = T なる対合、
⟨out|, |in⟩ を ι 不変とする。固有値 λ の一般固有空間の U^ι（ι 固定部分空間）
内での次元が 1 以下なら、a(n) = ⟨out|Tⁿ|in⟩ に n·λⁿ 項は現れない。

**証明.** T は U^ι を保ち a(n) = ⟨out|(T|_{U^ι})ⁿ|in⟩。λ 部分の係数多項式の
次数は T|_{U^ι} の λ での最大 Jordan ブロックサイズ − 1 ≤ 0。∎

**系（元文書の folding 記述の反証）.** 文書の通り sector が r ∈ {1..k−1} で
尽き、鏡映が r ↔ k−r の入れ替えで、境界データが対称と仮定する。k=3 では
sector は r = 1, 2 の 2 つで対角はどちらも 1·2 = 2、折り返し後の固定空間は
1 次元。命題 C より n·2ⁿ 項は不可能。しかし A_3(n) = (6+n)·2ⁿ で n·2ⁿ 項が
実在する。矛盾。よって「r ↔ k−r を同一視した後、奇数 k では最後の対角が
2×2 Jordan ブロックに乗る」という記述はそのままでは成立しない。
奇数 k では折り返し対とは**別の**、中央対角を持つ状態が必要である。∎

（この予言は §7–8 の構成で具体化された: k=3 で対角 2 を持つ状態は
「両端が生きた断片」と「相方の死んだ端を持つ断片 2 つ」の 2 種で、
端点予算の一方向遷移で結合され Jordan を作る。左右の鏡映とは無関係。）

## 6. 挿入過程（補題 C0/定理 C1 の舞台）

値の昇順挿入過程: 値 1..n+1 を孤立で置いた後、step t = 1, ..., n+k−1 で
値 v = n+1+t を挿入する。v の G 隣接先で既挿入のものは {1..t}
（v ~ u ⟺ v − u ≥ n+1 ⟺ u ≤ t）。そこで

- **起床**: 頂点 u は step u で起床する（以後任意の将来の挿入と隣接:
  u ≤ t < t′ なら (n+1+t′) − u ≥ n+1）。step t ≤ n+1 では小値 t が孤立で起床。
- **挿入**: v を起床済みの空きスロット 0/1/2 個へ接続（分岐・サイクル禁止）。
- **カプセル**: step s ≤ k−2 で挿入された値 n+1+s は step n+1+s（末尾 k−2
  step 内）で起床する。それ以外の挿入値（s ≥ k−1）は挿入後に容量が凍結される。

起床済み頂点は将来の全挿入と一様に隣接し、開封済みカプセルはちょうど
接続可能な大値と一致するので、状態は個体でなく役割別の個数＋断片の対形式で
足りる（類レベル計数の正当性）。

## 7. 補題 C0 — 欠損量の有界性（鍵となる新補題）

E(t) を step t までの総辺数、**def(t) := 2t − E(t)** とする。

**補題 C0.** (i) def は非減少。(ii) 完成可能な（ハミルトンパスに延長できる）
配置では常に def(t) ≤ k−1。(iii) 起床頂点の未使用容量
（2·孤立数 + 開端点数）は常に ≤ def(t)。

**証明.** (i) 各 step は辺を高々 2 本加える。(ii) 最終 step T = n+k−1 で
E(T) = 2n+k−1 だから def(T) = 2(n+k−1) − (2n+k−1) = k−1。単調性より途中も
≤ k−1。(iii) どの辺も作成時のターゲット端点は起床済みで、起床集合は単調
増加なので、各辺は少なくとも一方の端点が起床済み。よって
Σ_{起床} deg ≥ E(t)、未使用 = 2t − Σ_{起床} deg ≤ 2t − E(t) = def(t)。∎

**系.** 完成可能な状態では: 孤立 ≤ ⌊(k−1)/2⌋、開端点（A 端）≤ k−1、
凍結端点（F 端、最終パスの端点候補）≤ 2、カプセル記録 ≤ k−2、断片数 ≤ 2k。
すなわち**状態は k のみの関数で有界**。

（注: 「孤立頂点数が中間時点で n/2 程度まで漂流し得る」という素朴な見積りは
誤りであり、その反例可能性は (iii) — 辺の片端が必ず起床側にあること — で
排除される。この点が従来欠けていた。）

## 8. 定理 C1 — C-有限性と明示的表現式（ギャップ (4) の骨格）

状態を (d, a, aa, af, sp) とする: d = def(t)、a = 起床孤立数、
aa = 端が (A,A) の断片数、af = (A,F) の断片数、sp = 特殊断片（カプセル端
C_s を含む断片、および孤立カプセル）のソート済みリスト。枝刈り:
d ≤ k−1、F 端総数 ≤ 2、(F,F) 断片は最終 step 以外は死。受理: 全 step 終了後に
a = 0、未開封カプセルなし、断片がちょうど 1 つ。

**補題 C2（状態圧縮の正確性）.** 準備として 2 つの同一視を固定する。

(i) 履歴と forest の同一視。V_t := {1, ..., n+1+t} とする。G[V_t] の任意の辺は
{u, n+1+t′}（t′ ≤ t, u ≤ t′）の形である（差 > n より大きい方の端点は n+2
以上、小さい方は大きい方 − (n+1) 以下）。よって G[V_t] の linear forest F は、
「step t′ で頂点 n+1+t′ に F の当該辺を張る」という挿入履歴と 1 対 1 に対応し、
履歴の途中制約（ターゲット次数 < 2、サイクル禁止）は F が linear forest で
あることと同値である（次数超過・サイクルは、その最大頂点の挿入 step で
初めて生じる）。すなわち刈り込みなしの挿入過程は LF(G[V_t]) の各元を
ちょうど 1 回ずつ生成する。

(ii) 状態写像。F ∈ LF(G[V_t]) に対し頂点を類別する: u ≤ t は起床;
t < u ≤ n+1 は休眠小値（G 近傍は u+n+1 以上で未挿入なので自動的に deg 0）;
n+1+s（s ≤ k−2）は n+1+s ≤ t なら開封済み（起床扱い）、さもなければカプセル;
n+1+s（s ≥ k−1）は凍結。deg 1 の頂点（断片の端）に型 A（起床）/ C_s
（カプセル）/ F（凍結）を与え、σ_t(F) = (d, a, aa, af, sp) を
d = 2t − e(F)、a = 起床孤立数、断片の端型対の集計として定める。
刈り込み述語 P: 凍結孤立なし、F 端 ≤ 2、(F,F) 断片なし（最終挿入の結果と
してのみ許す）、d ≤ k−1。

主張: すべての t と状態 σ について、diagdp.rb の step を t 回適用した
ベクトルの σ 係数は #{F ∈ LF(G[V_t]) : σ_t(F) = σ, F は P を満たす} に
等しい。また P を満たさない F はハミルトンパスに延長できない。したがって
最終時点の受理状態の係数和は無向ハミルトンパスの総数に等しい。

**証明.** 後段（刈り込みの無害性）から。凍結頂点は以後のどの挿入頂点とも
隣接しない（n+1+t″ の隣接先 {1..t″} に入る大値 n+1+s は s ≤ t″−n−1 ≤ k−2、
すなわちカプセルに限る）。よって凍結孤立は任意の延長で deg 0 のままで
あり、F 端は延長不能な deg 1 のまま完成形の端点として残るから 3 個以上
あれば完成不能。(F,F) 断片は接続可能な端を持たず他の構造と合流できない
ので、最終挿入前に存在すれば完成形は 2 成分以上になる。d ≤ k−1 は
補題 C0(ii) そのもの。

前段は t の帰納法。t = 0 では両辺とも空 forest ただ 1 つ。step t+1 を
wake/open 段階と挿入段階に分けて、(α) 各段階の状態写像の変化が DP の
遷移と一致すること、(β) 同一状態の任意の 2 つの forest から各行き先状態
への子の個数が等しく、DP の多重度に一致することを示す。

(α) wake/open。F 自体は不変で σ の再計算のみ。t+1 ≤ n+1 なら u = t+1 が
起床する休眠小値（deg 0）で a が 1 増える。t+1 > n+1 なら s = t+1−n−1 の
カプセルが開封され、F 内 deg が 0 なら（solo 記録）孤立起床で a が 1 増え、
deg 1 なら当該断片の C_s 端が A 端に再分類され（(A,C_s)→(A,A) 等）、
deg 2 なら記録がなく変化しない。いずれも DP の wake/open 分岐と一致する。

(β) 挿入。F′ = F ∪ Δ、Δ は新頂点 w = n+2+t の辺集合（|Δ| ∈ {0,1,2}）。
まず合法性: w とターゲット u の G 隣接は u ≤ t+1、すなわち **u が起床済み
であることと同値**であり、u の個体名には依存しない（開封済みカプセル
n+1+s も n+1+s ≤ t+1 ⟺ 開封済 ⟺ 隣接、で整合）。ターゲット候補は起床
空きスロットで、類別と個数は状態から (孤立: a、AA 断片の端: 2aa、
AF 断片の A 端: af、sp 断片 X の A 端: cA(X) ∈ {0,1}) と読める。
行き先状態は選ばれた類のみで決まる（合成断片の端型は消費された側の
残り端の型で決まり、(A,A)/(A,F)/(A,C)/(F,C)/(C,C)/(F,F) への分類は
状態更新規則と一致）。よって子の個数は類ごとの組合せ数:
2 本では 異孤立対 C(a,2)、孤立×AA端 a·2aa、孤立×AF端 a·af、
孤立×spA a·cA(X)、異 AA 断片の端対 2aa(aa−1)、AA端×AF端 2aa·af、
AA端×spA 2aa·cA(X)、異 AF 対 C(af,2)、AF×spA af·cA(X)、
異 sp 対 cA(X)cA(Y)。サイクルを作るのは同一断片の 2 端対のみで、
それが存在するのは AA 断片に限る（sp の A 端は高々 1、AF は 1、孤立は
単一頂点でターゲット相異則により除外）から、除外は完全である。
1 本ではターゲット 1 個の選択（各類の個数倍）で、w の残り端は
カプセル（t+1 ≤ k−2）なら C_{t+1}、さもなければ F となり d が 1 増える。
0 本はカプセルの solo 記録（d が 2 増える）に限り、非カプセルは凍結孤立と
なって P により除かれる。以上は DP の遷移列挙と 1 対 1 に対応する。

帰納法により全 t で係数 = forest 数。「状態が捨てた情報（頂点名・断片の
内部長）が将来に影響しない」ことは、この等式が全 t で保たれることとして
帰納的に示されており、別個の議論を要しない。受理: 最終時点で a = 0・
未開封カプセルなし・凍結孤立なし（P）なら deg 0 の頂点はなく、断片数 1 と
合わせて F は V を張る単一パス。逆も明らか。∎

**定理 C1.** n ≥ k で

    A_k(n) = 2 · F( U · Λ^{n−k+3} · h )

が成り立つ。h は頭部（step t = 1..k−2、カプセル生成期）を適用した状態
ベクトル、Λ はバルク 1 step の転移（step 写像は t に 3 述語 t ≤ n+1・
t ≤ k−2・t = n+k−1 を通してしか依存しないので t ∈ [k−1, n+1] で同一写像）、
U は尾部 k−2 step（開封番号 s = 1..k−2 で添字づけられ n に依存しない写像）の
合成、F は受理汎関数。すべて非負整数係数、状態空間の次元は k のみで有界
（B(k) とする）。したがって **A_k(n) は各固定 k で次数 ≤ B(k) の定数係数
線形漸化式を満たす**（Cayley–Hamilton を Λ の到達部分空間に適用）。

**証明.** 状態空間の有限性は補題 C0 の系。状態圧縮の正確性——各時点の
状態係数が forest 数に等しく、受理和がハミルトンパス数に等しいこと——は
補題 C2。step 写像が t に 3 述語を通してしか依存しないことと、頭部・尾部の
長さが k−2（k のみ）であることからバルクは定常。バルク step 数は
(n+1) − (k−1) + 1 = n−k+3。∎

**表現の正当性の三重検証（補題 C2 と実装の対応の傍証）.** 数学的な正確性は
補題 C2 が担う。以下は、実装が補題 C2 の場合分けを正しく写していることの
独立な傍証である。
1. 頂点個体レベルの挿入シミュレーションが基準値（ハミルトンパス直接列挙）と
   完全一致（k=3, n=3,4; k=4, n=4）。
2. 個体シミュレーション由来のクラス状態分布とクラス集約 DP が全 step で
   分布一致（k=3, n=3）。
3. 既知厳密値と一致: k=3 で (6+n)2ⁿ を n=8 まで、k=4,5,6 で A179962/3/4 を
   複数項、k=7 で A_7(7) = 147689145984、k=8 で A_8(8) = 108370981896192
   （後者は本セッション前半で三系統独立計算により相互検証済みの値）。

（開発中に 2 つの実装バグ — カプセル 1 辺挿入の F 端二重計上、特殊断片対の
消費時の添字ずれ — が検証 1, 2 により特定・修正された。これが上の三重検証を
方法として採用した理由である。）

## 9. 生存刈り込み

**補題 9.1.** 状態 s が「どの m ≥ 0 でも F(U Λ^m e_s) = 0」を満たすとき死と

なら各項が 0）。したがって死状態の除去は A_k(n) を変えず、表現式は生存状態
のみの上で成り立つ。∎

## 10. 認証補題と各 k での完全証明

**補題 10.1（認証）.** s(n) = φ(Λ^{n−n₂} v)（Λ は D 次元空間上、n ≥ n₂）とし、
C ∈ Z[X] をモニック d 次とする。b(n) := C(shift)s(n) が D 個の連続点で 0
なら、それ以降のすべての n で 0。

**証明.** b(n) = φ(Λ^{n−n₂} C(Λ)v) は Λ の特性多項式（モニック整数、次数 D）
の与える前進漸化式を満たす（Cayley–Hamilton）。連続 D 点で 0 なら前進帰納で
恒等的に 0。∎

**注記（添字規約と実装の対応）.** シフトを (Es)(n) = s(n+1) と定める。
b(n) = C(E)s(n) = s(n+d) − Σ_{i=1..d} c_i s(n+d−i) であり、certify.rb が
各検査点 m で確かめる後退形の等式 s(m) = Σ_i c_i s(m−i) は b(m−d) = 0 に
等しい。よって出力の「n_lo..nmax で成立」は、b が [n_lo−d, nmax−d] の
連続 (nmax − n_lo + 1) 点で零であることを意味し、補題 10.1 により
nmax − n_lo + 1 ≥ D なら b ≡ 0、すなわち漸化式はすべての m ≥ n_lo で
成立する。補題としては D 点で十分だが、スクリプト（および §10 の表の
「必要長」）は安全側の D+1 点を要求している。値の窓としては D+1 個の
残差を作るためにさらに d 個前の項（計 D+1+d 項）を用いる。

よって定理 C1（次数上界 D = 閉包サイズ）＋有限窓の厳密値検証が、その k に
ついての主定理の完全な証明を与える。数学的には長さ D + deg C_k の値の窓で
十分であり、現行スクリプトは安全側に D + 1 + deg C_k 項を使用する。実行結果:
